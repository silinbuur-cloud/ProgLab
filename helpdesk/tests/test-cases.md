## 4. Оставшиеся ограничения

- Данные хранятся только в браузере (localStorage), без сервера и общей базы.
- Нет авторизации и разделения ролей: все действия выполняет один оператор.
- Срок SLA считается в календарных часах, без учета рабочего графика и выходных.
